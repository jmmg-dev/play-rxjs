# Play RxJS v2

Interactive, bilingual (English / Spanish) RxJS documentation. Every example is a **live playground**: edit the code, press **Run** (or `Ctrl + Enter`) and watch the console react in real time. **Reset** restores the original example.

## Tech stack

- Angular 22 (standalone, signals, zoneless) with SSR + prerendering (SSG) via `@angular/ssr`
- RxJS 7.8
- CodeMirror 6 (editor, lazy loaded) + Lezer (identical syntax highlighting on the server)
- Sucrase (in-browser TypeScript transpilation, lazy loaded)
- Express server, deployable on Vercel
- Vitest + jsdom (unit tests, run through Angular's `@angular/build:unit-test` builder) with v8 coverage
- GitHub Actions (tests and coverage gate on every push / pull request to `main`)

## How it works

| Piece                                                       | Where                                                            |
| ----------------------------------------------------------- | ---------------------------------------------------------------- |
| Sections, operators and their order                         | `src/app/content/catalog.ts`                                     |
| Example code + sandbox controls (buttons, inputs…)          | `src/app/content/examples/*.ts`                                  |
| Texts (EN / ES), UI strings and SEO copy                    | `src/app/core/i18n/locales/{en,es}.json`                         |
| Playground (editor, Run / Stop / Reset, console)            | `src/app/playground/`                                            |
| Marble diagrams (generated by running the real operators)   | `scripts/generate-marbles.mjs` -> `src/app/content/marbles.json` |
| SEO (title, meta, canonical, hreflang, Open Graph, JSON-LD) | `src/app/core/seo.service.ts`                                    |
| Sitemap (`/sitemap.xml`, with hreflang alternates)          | `src/app/core/sitemap.ts`                                        |

- **URLs are localized**: `/en/...` and `/es/...`. `/` redirects to the preferred language (cookie → `Accept-Language`).
- **Every documentation page is prerendered** for both languages (330 pages), so the full documentation reaches crawlers and users already rendered. Unknown pages are rendered on demand with a real `404` status.
- **Sandbox**: user code is transpiled with Sucrase and executed inside a throw-away `<iframe sandbox="allow-scripts">` (opaque origin). Run / Stop / Reset destroy the iframe, so intervals and subscriptions never leak. `import ... from 'rxjs'`, `'rxjs/ajax'`, `'rxjs/fetch'` and `'rxjs/webSocket'` work as in a real project. A simulated `userService` (HTTP with latency) is available for the data examples.

### Adding an operator

1. Add `{ id: 'myOperator' }` to the right category in `catalog.ts`.
2. Add its code (and optional `ui` controls) in `content/examples/<category>.ts`.
3. Add `title`, `description` (the operator) and `example` (what the example does, shown under the playground's Info button) under `<category>.myOperator` in both locale files.
4. If a marble diagram makes sense, add its spec to `scripts/generate-marbles.mjs` and run `npm run marbles` (`-- --print` shows them as text).
5. Run `npm run check:examples` — it verifies that every example compiles, runs and has EN/ES texts.

## Development

Requires Node `^22.22.3 || ^24.15.0 || >=26`.

```bash
npm install
npm start               # http://localhost:4200 (SSR dev server)
npm run build           # dist/play-rxjs (browser + server + prerendered pages)
npm run serve:ssr       # http://localhost:4000 (production server)
npm run check:examples  # smoke test of every example
npm test                # unit tests, single run
npm run test:watch      # unit tests in watch mode
npm run test:coverage   # unit tests + coverage report (fails below 90 %)
```

## Testing

Unit tests use **Vitest** with a **jsdom** environment, run by Angular's official builder (`@angular/build:unit-test`, `test` target in `angular.json`). Components are tested with `TestBed`, without extra testing libraries.

- **Where**: each `*.spec.ts` sits next to the file it tests (`seo.service.ts` → `seo.service.spec.ts`). `src/test-setup.ts` adds the text-range geometry jsdom lacks, which CodeMirror needs.
- **What is covered**: the whole `src/app` code — catalog, i18n, navigation, SEO / JSON-LD, sitemap, routes (including the 404 cases), layout (header, sidebar, footer, search palette, language switch), pages, playground (edit, run, console, stop, reset), sandbox messaging, CodeMirror editor and marble diagrams. Tests check behaviour (what the user sees and the resulting URLs / meta tags), have no real network and do not depend on the clock.
- **Coverage gate**: v8 coverage over `src/app/**` with a **90 %** minimum for lines, statements, functions and branches (`coverageThresholds` in `angular.json`); `npm run test:coverage` fails below it. The HTML report is written to `coverage/play-rxjs/index.html`. Only bootstrap and provider/route configuration files are excluded (`main*.ts`, `server.ts`, `app.config*.ts`, `app.routes.server.ts`).
- **CI/CD**: `.github/workflows/ci-cd.yml` (job `checks`) runs `npm ci`, the `lint` and `format:check` scripts when they exist, and `npm run test:coverage` on every push and pull request to `main` / `master` (Node version from `.nvmrc`) and uploads the coverage report as an artifact. To block merging when it fails, enable a branch protection rule that requires the `checks` check.

Server rendering and real browser behaviour (layout, animations, the sandbox iframe actually running RxJS) are not covered by unit tests; `npm run check:examples` complements them by running every example against the real RxJS.

## Deploying to Vercel

The repo is ready to import in Vercel (no framework preset needed, everything is in `vercel.json`):

- `dist/play-rxjs/browser` (assets + prerendered pages) is served from the CDN.
- Any other request goes to the `api/index.mjs` function, which runs the Angular SSR Express handler (`reqHandler`).

Before going live with a custom domain, update:

- `SITE_URL` in `src/app/core/site.ts` (canonical, hreflang, Open Graph, sitemap)
- `public/robots.txt` (sitemap URL)
- `security.allowedHosts` in `angular.json` (hosts allowed to be server-rendered)
